# WOODLAB.MD

Сайт изделий из дерева и металла на заказ в Молдове.

Статический сайт без сборки: index.html, styles.css, app.js, assets/.
Каталоги и карточки доступны через catalog.html и product.html.

Форма на демонстрационной версии позволяет скачать запрос. Для реальной отправки нужно подключить обработчик и контакты компании.
